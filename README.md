# Restaurant Management System

A Python-based restaurant management application developed using Object-Oriented Programming (OOP) and Tkinter.

## Features

- Customer registration, search, editing, and deletion
- Restaurant menu management
- Order registration and management
- Invoice generation and saving
- Sales statistics
- Exporting orders to Excel
- Persistent data storage using Pickle
- Graphical user interface using Tkinter

## Technologies

- Python 3
- Tkinter
- Object-Oriented Programming (OOP)
- Pickle
- OpenPyXL
- Persiantools

## Installation

1. Download or clone the repository.
2. Install the required libraries:

```bash
pip install -r requirements.txt
```

1. Run the application:

```bash
python tkinter_ui.py
```

## Project Structure

- `customer.py`: Customer management
- `menu.py`: Restaurant menu management
- `order.py`: Order management
- `tkinter_ui.py`: Graphical user interface
- `test_restaurant.py`: Project testing
- `main.py`: Additional entry-point script

## Notes

Customer and order data files are excluded from the public repository to protect stored information.
